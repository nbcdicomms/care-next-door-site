# The Care Next Door — Landing Page

Plain HTML/CSS/JS. No build step, no framework. This is a static site.

## Files
- `index.html` — the whole page
- `assets/` — poster, logo, flyer, and the video clip used in the About section

## To edit
Open `index.html` in any text editor. Copy, colors, and section order all live in that
one file (styles are in a `<style>` block near the top, content further down).

## To go live on Vercel
See the chat for full instructions. Quick version:
1. Create a free account at vercel.com
2. Install the CLI: `npm install -g vercel`
3. From this folder, run: `vercel`
4. Follow the prompts (accept defaults — it's a static site)
5. Your first link is live. Run `vercel --prod` to publish it as your production URL.
